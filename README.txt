# 📦 Fullstack React + Spring Boot Application

This repository contains a **complete full-stack e-commerce application** built using **React (Frontend)** and **Spring Boot (Backend)**. The project is structured in progressive sections, each focusing on a specific concept, gradually building a production-ready system.

---

# 🚀 Tech Stack

* **Frontend**: React, Redux Toolkit, Tailwind CSS, Context API
* **Backend**: Spring Boot, Spring Security, JWT
* **Database**: MySQL, Hibernate (JPA)
* **Tools**: Postman, Git, VS Code, IntelliJ

# ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/fullstack-react-springboot.git
```

### 2. Backend Setup

```bash
cd backend
./mvnw spring-boot:run
```

### 3. Frontend Setup

```bash
cd frontend
npm install
npm start
```
