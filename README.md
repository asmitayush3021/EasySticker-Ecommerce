A **production-ready full-stack e-commerce application** built using **React (Frontend)** and **Spring Boot (Backend)**.
The project is organized into **progressive sections**, making it suitable for both **learning and real-world implementation**.

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/fullstack-react-springboot.git
cd fullstack-react-springboot
```

---

### 2️⃣ Backend Setup

```bash
cd backend
./mvnw spring-boot:run
```

Backend runs on: `http://localhost:8080`

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm start
```

Frontend runs on: `http://localhost:3000`
